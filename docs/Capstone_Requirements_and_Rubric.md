# Capstone Project: Build an AI Startup

*Source: Module 04 slides (slides 2–5), MGMT 298E – Building LLM-Powered and Agentic AI Applications. Syllabus details at the bottom.*

> **Ship a real AI-powered product that solves a real problem.**
> It should be live, usable, and ready to charge for.

---

## What We're Looking For

- Clear problem statement
- Thoughtful system design
- Working implementation
- Live demo
- Lessons learned & future improvements

---

## Expected Outcomes

Build and deploy a **fully functional, end-to-end AI product** that solves a real problem and is **accessible via a live URL, not running on localhost**.

### Must-haves

- [ ] **User sign-up and login**
- [ ] **An AI backend** that delivers the product's core value
- [ ] **Payments through Stripe** (sandbox/test mode)
- [ ] **A well-structured GitHub repository** and clear system design decisions that show strong engineering and product thinking
- [ ] **A short write-up** covering the problem, solution, architecture, and next steps

### Expected path

**Idea → scoped PRD → architecture → implementation → deployment**

---

## Grading Rubric (100 points)

| Criteria | What we look for | Points |
|---|---|---:|
| **Business problem & product thinking** | A real, specific problem; a clear target user; a reason AI is the right solution | 15 |
| **Implementation completeness** | How much of the scoped product works end to end: login, AI feature, payment flow, core user journey | 25 |
| **AI design framework** | An AI backend, plus handling of errors and edge cases | 20 |
| **Deployment & production readiness** | A live, stable URL; working Stripe sandbox checkout; secrets handled securely; graceful error states | 15 |
| **Engineering quality & system design** | Repo structure, readable code, a README, an architecture diagram, and justified design decisions | 10 |
| **Write-up** | A concise, well-structured write-up (max 4–5 pages) | 10 |
| **Teamwork & presentation** | Clear ownership, real collaboration, and a confident team presentation | 5 |
| | **Total** | **100** |

---

## Self-Check Before Submission

**Product (15)**
- [ ] Problem is specific and real; target user is named
- [ ] Clear argument for why AI (an LLM) is the right tool

**Implementation (25)**
- [ ] Sign-up/login works
- [ ] Core AI feature works end to end
- [ ] Stripe checkout flow works
- [ ] Core user journey completes without breaking

**AI design (20)**
- [ ] AI backend delivers the core value
- [ ] Errors and edge cases are handled (bad input, model/API failures, empty results, etc.)

**Deployment (15)**
- [ ] Live, stable public URL (not localhost)
- [ ] Stripe sandbox checkout works in production
- [ ] Secrets in environment variables, not committed to the repo
- [ ] Graceful error states shown to the user

**Engineering (10)**
- [ ] Clean repo structure and readable code
- [ ] README
- [ ] Architecture diagram
- [ ] Design decisions written down with reasons

**Write-up (10)**
- [ ] 4–5 pages max: problem, solution, architecture, next steps / lessons learned

**Team & presentation (5)**
- [ ] Clear ownership per team member
- [ ] Rehearsed live demo
